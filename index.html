첫 결과를 학교 문서에 맞게 다듬는 수정 프롬프트

다음 기준으로 다시 수정해줘.
1. 전체 분량을 약 20% 줄여 핵심만 남겨줘.
2. 학생·학부모가 바로 이해할 수 있는 쉬운 말로 바꿔줘.
3. 불필요하게 불안을 주는 표현은 부드럽고 정확하게 수정해줘.
4. 학교에서 확정하지 않은 의료·법률·정책 내용을 단정하지 말고 "확인 필요"라고 표시해줘.
5. 핵심 행동수칙은 표 또는 체크리스트로 다시 정리해줘.
6. 학교명·날짜·연락처처럼 사용자가 직접 넣어야 하는 부분은 [학교명], [날짜], [연락처]처럼 표시해줘.
7. 마지막에 교사가 최종 검수해야 할 항목을 5개 이내로 제시해줘.

너는 15년 경력의 대한민국 [초등학교/중학교/고등학교/특수학교] 보건교사야.

다음 정보를 바탕으로 [학교급/학년] 학생과 학부모에게 배포할 "[감염병 또는 건강 주제] 예방 가정통신문" 초안을 작성해줘.

[입력 정보]
- 학교급/학년: [예: 중학교 1학년]
- 주제: [예: 인플루엔자 예방]
- 현재 상황 또는 계절적 배경: [예: 환절기 이후 호흡기 증상 학생이 증가하고 있음]
- 학생이 실천할 행동: [예: 손 씻기, 기침 예절, 마스크가 필요한 상황, 충분한 휴식]
- 학부모에게 요청할 협조사항: [예: 등교 전 건강상태 확인, 증상 시 진료 및 학교 연락]
- 학교에서 안내가 필요한 내용: [예: 보건실 이용, 결석·출석 관련 확인 경로]
- 분량: A4 1장 이내

[작성 조건]
1. 제목 → 인사말 → 현재 상황 → 주요 증상/주의사항 → 학생 예방수칙 → 가정 협조사항 → 확인이 필요한 안내 → 문의처 순서로 작성해줘.
2. 학부모가 읽기 쉬운 짧은 문장과 명확한 소제목을 사용해줘.
3. 공포를 유발하거나 낙인을 만들 수 있는 표현은 사용하지 말아줘.
4. 의학적 수치, 격리·등교중지 기준, 법령·정책은 임의로 만들지 말고 최신 공식 지침 확인이 필요한 부분에 [공식자료 확인 필요]라고 표시해줘.
5. 학교명·담당자·연락처·발송일은 임의 작성하지 말고 [학교명], [담당자], [연락처], [날짜]로 남겨줘.
6. 마지막에 "교사 최종 확인 체크리스트"를 5개 항목으로 제시해줘.

가정통신문을 한 번 더 다듬기

방금 만든 가정통신문을 학교 배포용으로 한 번 더 다듬어줘.

- 전체 문장을 약 20% 더 짧게 줄여줘.
- 학부모가 스마트폰으로 읽기 쉽게 문단을 짧게 나눠줘.
- 전문용어는 쉬운 말로 바꾸고, 꼭 필요한 전문용어는 괄호로 설명해줘.
- 학생에게 불안을 줄 수 있는 문장은 차분하고 행동 중심의 표현으로 바꿔줘.
- 확정되지 않은 의료·출결·법령 기준은 [확인 필요]로 표시해줘.
- 마지막 행동수칙은 "학생이 할 일 / 가정에서 할 일 / 학교에 연락할 때" 3열 표로 정리해줘.
